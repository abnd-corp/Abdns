# Security policy

Please do not open a public issue for a vulnerability. Use GitHub private reporting: **Security** tab of this repository, then **Report a vulnerability**.

Merci de ne pas ouvrir d'issue publique pour une faille : onglet **Security** du dépôt, puis **Report a vulnerability**.

Scope that matters most: anything that sends a query in clear while an encrypted server answers, leaks the upstream token, or lets a local user change the DNS of the machine.
